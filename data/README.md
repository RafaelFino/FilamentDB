# Data\n\nDiretório único dos bancos SQLite do FilamentDB e dos artefatos versionados de suporte ao banco de preços.\n\n## Bancos em runtime\n\n- `filament.db` — catálogo canônico.\n- `inventory.db` — dados mutáveis do inventário.\n- `price-history.db` — histórico de preços e ofertas.\n\nTodos os bancos ficam no mesmo diretório definido pelo `DB_PATH`. Se `DB_PATH` não for configurado, o padrão é `data/filament.db` dentro da solução.\n\nOs bancos são ignorados pelo Git.\n\n## Arquivos versionados\n\n- `price-history.schema.sql` — schema do banco de preços.\n- `price-history.seed.json` — baseline inicial.\n- `price-history.README.md` — documentação específica do histórico.\n
